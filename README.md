# 우리학교 공간기억 · 3D Harness

**360도 사진으로 학교를 둘러보고, 지점을 눌러 이동하는 결과부터 완성하는 Codex Astra × Blender MCP 하네스입니다.**

선생님은 긴 프롬프트 대신 아래 한 문장으로 시작하세요. 이 저장소는 작업 지침과 점검 도구이며, 촬영 자료 없이 완성된 학교 투어를 제공하는 제품은 아닙니다.

## 시작하기

1. 이 저장소를 내려받아 **폴더 자체를 Codex 프로젝트로 열고 GPT-6 Astra를 선택**합니다.
2. Codex에 **“Blender MCP 자동 설치하고 연결 확인해줘”**라고 합니다. [Windows 자동 설치](docs/setup.md)가 필요한 프로그램·애드온·Codex 설정을 처리합니다. 설치 후 Blender를 열고 Codex 세션을 다시 시작합니다. 사진 투어는 연결 전에도 진행할 수 있습니다.
3. 촬영 자료를 로컬 `input/` 폴더에 넣고 아래 문장을 보냅니다. 기존 작업이 있으면 그 폴더 경로도 알려주세요.

> input의 학교 360 사진으로 지점을 눌러 이동하는 공간기억 투어를 만들어줘. 먼저 샘플 3장으로 작동하게 하고, 화면을 확인해서 고친 뒤 나머지로 확장해줘.

실패한 작업을 이어받길 원하면:

> 기존 작업은 [폴더 경로]야. 자료와 현재 화면을 보고 안 되는 원인부터 고쳐서 실행 가능한 결과로 마무리해줘.

자유롭게 걸어 다니는 실제 3D가 필요하면:

> 촬영한 공간 안을 자유롭게 걸어 다니고 싶어. 입력 자료와 PC 사양으로 가능한지 작은 구간부터 검증해줘.

## 왜 이렇게 구성했나요?

| 원하는 경험 | 먼저 쓸 방법 | Blender 역할 |
|---|---|---|
| 제자리에서 둘러보기 + 다른 촬영 지점으로 이동 | 360 파노라마 투어 | 필요 시 투영·방향 확인, 지도·보조 모델 |
| 이동하면서 가까운 물체와 먼 물체의 위치 관계가 달라짐 | 다중 시점 촬영 → 복원 → 3DGS/메시 뷰어 | 정리, 스케일·카메라·메시 편집 |
| 치수·벽·가구를 직접 수정 | 실측/도면 기반 모델링 | 주 제작 도구 |

**360 사진을 구에 붙여 카메라를 움직이는 것만으로 실제 3D가 복원되지는 않습니다.** 선생님의 실패 원인은 아직 실제 자료를 보지 못해 확정할 수 없습니다. 이 구분부터 검사하도록 만들었습니다.

## 매번 읽는 것은 하나

[AGENTS.md](AGENTS.md)만 공통 지침입니다. 작업에 따라 [투어](recipes/tour.md), [Blender](recipes/blender.md), [복원](recipes/reconstruction.md) 안내 하나를 추가로 읽습니다. [조사 근거](docs/research.md)와 [평가 방법](eval/README.md)은 필요할 때만 엽니다. 새 대화에서는 `STATE.md`로 이어갑니다.

사진 점검 도구는 로컬에서 실행합니다(Python 3.11 이상).

```powershell
python -m pip install -r requirements.txt
python scripts/inspect_panos.py input --out work/intake
python -m unittest discover -s tests -v
```

점검 결과는 2:1 비율 **후보**이지 완전한 360 사진 인증이 아닙니다. 기본 미리보기는 최대 6장입니다. 재점검할 때는 `--out work/intake-02`처럼 새 폴더를 지정합니다. 원본·미리보기·작업 결과는 Git에서 제외됩니다. 공유하려면 공개할 결과만 별도로 검토하세요.

검증 범위와 한계: [VALIDATION.md](VALIDATION.md). 별도 API 키·유료 생성 서비스·대규모 프레임워크를 기본으로 요구하지 않습니다. 비용 및 최고 품질을 보장하는 문구 대신 같은 입력으로 결과와 사용량을 비교합니다.
